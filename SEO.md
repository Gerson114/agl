# SEO — Chonnostech

O site apresenta sistemas internos sob medida e automação de processos para empresas. O domínio principal é `https://chonnostech.com`.

- Página inicial: visão geral dos serviços, com acesso a sistemas internos e automações.
- `/sistema`: módulos internos, gestão de tarefas, equipes e dashboards.
- `/automacoes`: processos que podem ser avaliados, etapas de implementação e perguntas frequentes.
- `/solucoes`: comparação das ofertas; `/contato`: solicitação de proposta.
- `/sitemap.xml` lista as rotas públicas; `/robots.txt` aponta para o sitemap.
- Cada página tem um título, uma descrição e uma URL canônica.
- Dados estruturados descrevem a empresa, seus serviços e as perguntas da página de automações.

Após publicar, confira a propriedade e envie `https://chonnostech.com/sitemap.xml` no Google Search Console. Verifique também se o domínio com `.com.br` redireciona permanentemente para o domínio principal.
